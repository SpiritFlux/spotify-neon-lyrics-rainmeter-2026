SpotifyNeonLyrics - Quick help

1) Install the WebNowPlaying plugin + browser extension, then play a song in Spotify.
2) Load Main.ini. Double-click the lyrics (or right-click > Customize layout) to open Settings.
3) Settings apply instantly. Tabs: Layout / Look / Text / Motion / Saved / More.
   - Lyrics only = no box, just text.   - Saved = name and reload your layouts.
   - More > This song's timing = fix lyrics that run early/late for one song.

Troubleshooting
- "No lyrics found": LRCLIB does not have that track.
- Missing characters: Text tab > pick a font with your script (Nirmala UI for Indic, Yu Gothic UI for CJK).
- Skin Lua/INI files must be saved as UTF-16 LE.
